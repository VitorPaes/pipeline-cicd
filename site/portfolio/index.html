Potencial bancário brasileiro

Integração de dados públicos para investigar oportunidades de expansão bancária nos municípios brasileiros.

  • Python
  • Pandas
  • BigQuery
  • Google Cloud Storage

O problema

Como combinar capacidade econômica, adoção digital e presença bancária para comparar oportunidades entre municípios?

A entrega

Pipeline em camadas raw, trusted e analytics, análise exploratória e três versões do Índice de Potencial Bancário (IPB).

Fluxo de dados

origem → consumo
  1. 01Fontes públicasIBGE · BCB · Anatel
  2. 02Ingestão e tratamentoPython · raw / trusted
  3. 03Índice e análiseBigQuery · analytics
Explorar detalhes técnicos +
Integração
Padronização por código IBGE e consolidação dos indicadores municipais.
Qualidade
Testes de dados e análise de valores ausentes, outliers e correlações.
Comparação
Três formulações do índice para estudar a sensibilidade dos rankings.

Integro a equipe com Hermes Augusto, Lúcio Franchi Cruz e Nathalia Miranda. O projeto segue em desenvolvimento, com refinamento e validação de negócio previstos no roadmap.
