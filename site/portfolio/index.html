01
IPB · Projeto coletivo de MBA

Onde há potencial bancário?

Integração de dados públicos para investigar oportunidades de expansão bancária nos municípios brasileiros.

  • Python
  • Pandas
  • BigQuery
  • Google Cloud Storage
+

O problema

Como combinar capacidade econômica, adoção digital e presença bancária para comparar oportunidades entre municípios?

A entrega

Pipeline em camadas raw, trusted e analytics, análise exploratória e três versões do Índice de Potencial Bancário (IPB).

Fluxo de dados

  1. 01
    Fontes públicas

    IBGE · BCB · Anatel

  2. 02
    Ingestão e tratamento

    Python · raw / trusted

  3. 03
    Índice e análise

    BigQuery · analytics

Integração
Padronização por código IBGE e consolidação dos indicadores municipais.
Qualidade
Testes de dados e análise de valores ausentes, outliers e correlações.
Comparação
Três formulações do índice para estudar a sensibilidade dos rankings.

Integro a equipe com Hermes Augusto, Lúcio Franchi Cruz e Nathalia Miranda. O projeto segue em desenvolvimento, com refinamento e validação de negócio previstos no roadmap.

02
Pipeline analítico local

Uma plataforma de dados, do início ao fim.

Dados de vendas e logística organizados em uma plataforma analítica com modelagem, testes e auditoria.

  • DuckDB
  • dbt
  • MinIO
  • Streamlit
  • Docker
+

O problema

Como transformar arquivos de pedidos e itens em uma base consistente para analisar vendas e logística?

A entrega

Modelos dimensionais no DuckDB, verificações com dbt, reconciliação de registros e dashboard em Streamlit.

Fluxo de dados

  1. 01
    Ingestão

    CSV · MinIO

  2. 02
    Modelagem e testes

    dbt · DuckDB

  3. 03
    Consumo

    Streamlit

Modelagem
Camadas staging, intermediate e marts, com dimensões e fato de itens de pedidos.
Integridade
Testes de unicidade, preenchimento e relacionamento entre fato e dimensões.
Operação
Script de execução por etapas, logs e auditoria de contagem de registros.

A arquitetura concentra armazenamento e processamento no ambiente local. O repositório reúne código, documentação de requisitos e planos de teste.

Ver repositório ↗Arquitetura ↗Modelos e testes ↗Execução do pipeline ↗
03
Desafio Magalu · PySpark

Vendas, comissões e modelagem.

Transformação de dados de e-commerce em dimensões, fatos e análises de vendas por parceiro.

  • PySpark
  • Python
  • Star schema
  • Jupyter
+

O problema

Como organizar pedidos, produtos e parceiros para calcular comissões e comparar o desempenho mensal?

A entrega

Notebook PySpark com modelo dimensional, agregações mensais, regras de comissão e rankings por parceiro.

Fluxo de dados

  1. 01
    Origem

    Tabelas CSV

  2. 02
    Transformação

    Joins · dimensões · fato

  3. 03
    Análise

    Comissões · rankings

Modelagem
Construção de dimensões de localização, produto, parceiro e cliente, além da fato de pedidos.
Regras de negócio
Agregações de vendas e aplicação das regras de bônus e comissão do desafio.
Análise temporal
Window functions para identificar os três maiores parceiros em cada mês.

Solução desenvolvida em notebook para um desafio de Analytics Engineering. O código documenta as transformações e as regras aplicadas aos dados do exercício.

04
Desafio PAN · SCR

Crédito em uma base analítica.

Preparação de variáveis de crédito a partir de modalidades, vencimentos e faixas de atraso.

  • SQL
  • Python
  • SQLite
  • Pandas
+

O problema

Como reorganizar dados no formato SCR para facilitar análises e a construção de variáveis de crédito?

A entrega

Base analítica book_scr, com agregações por modalidade, faixas acumuladas e exportação em CSV.

Fluxo de dados

  1. 01
    Base de entrada

    SCR · modalidades

  2. 02
    Preparação

    SQL · faixas de crédito

  3. 03
    Saída

    Book analítico · CSV

Transformação
Junção de modalidades e geração de expressões SQL para agregações de crédito.
Variáveis
Saldos a vencer e vencidos organizados em faixas e janelas acumuladas.
Exploração
Consultas e gráficos para analisar a distribuição das modalidades de crédito.

O foco do desafio é a preparação de dados e variáveis para análise de crédito, com consultas exploratórias e exportação da base resultante.
